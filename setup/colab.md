# Using Google Colab

Colab lets you run Python notebooks in a web browser, without a local Python installation.

1. Open a course lesson using its **Open in Colab** link (links will be available once verified notebooks are published).
2. Select **File → Save a copy in Drive**. Your edits to a viewed GitHub notebook do not change this repository.
3. Run the cells from top to bottom. If something looks wrong, choose **Runtime → Restart session** and rerun.
4. Store only public or approved data in Colab. Restricted research data may not be permitted in cloud services.

Sessions and installed packages do not persist forever. Keep your own copy in Drive.

**Project status:** the spec calls for a working Colab launch link on every lesson; no lesson has been released yet.
