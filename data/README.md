# Course data

Only small, rights-checked public or simulated teaching data belong here. The course's original licensing remains undecided; that does not change the third-party data terms below.

## `gapminder.csv`

- **Question:** Do people live longer in richer countries?
- **Source:** Gapminder historical teaching extract, packaged by Jennifer Bryan in the R `gapminder` package. [Package documentation](https://jennybc.github.io/gapminder/), [upstream dataset documentation](https://github.com/jennybc/gapminder/blob/391b5a40d3574c3b89d889dd7d72f7f3fdb4a70c/man/gapminder.Rd).
- **Exact download:** [upstream TSV](https://raw.githubusercontent.com/jennybc/gapminder/391b5a40d3574c3b89d889dd7d72f7f3fdb4a70c/inst/extdata/gapminder.tsv), commit `391b5a40d3574c3b89d889dd7d72f7f3fdb4a70c`.
- **Retrieved:** 2026-11-11.
- **License:** CC0, explicitly declared in the [upstream package DESCRIPTION](https://github.com/jennybc/gapminder/blob/391b5a40d3574c3b89d889dd7d72f7f3fdb4a70c/DESCRIPTION). [CC0 terms](https://creativecommons.org/publicdomain/zero/1.0/). Redistribution and adaptation are permitted. Credit: Gapminder and Jennifer Bryan; this is not an endorsement.
- **Preparation:** `python scripts/prepare_data.py`. Uses only Python's standard library, verifies the upstream SHA-256, renames columns, converts tabs to commas, and preserves all original values and row order. No rows are removed, no values are imputed, and no figures are rounded. To verify: `python scripts/prepare_data.py --check` (network required), or add `--source /path/to/gapminder.tsv` for an offline check.
- **Upstream SHA-256:** `f74275b4a2f4a7c8e3a09a752f9d6e43d1759d78d5cbfdebaaa3e1a6efc68f78`.
- **Size and coverage:** 1,704 rows, 6 columns; 142 countries × 12 five-year observations, 1952–2007. A row is a country-year. This filtered teaching extract contains no missing values in these six columns. It is not a representative sample of individuals, a complete country list, or current statistics. Continent labels and country boundaries follow the historical source.

| Course column | Upstream name | Meaning / units |
| --- | --- | --- |
| `country` | `country` | Country name in the historical extract |
| `region` | `continent` | Broad continent grouping: Africa, Americas, Asia, Europe, Oceania; no new classification added |
| `year` | `year` | Calendar year, every five years |
| `life_exp` | `lifeExp` | Life expectancy at birth, years |
| `population` | `pop` | Population, people |
| `gdp_pc` | `gdpPercap` | GDP per person, US dollars adjusted for inflation, as described by the upstream package; not current dollars or household income |

The upstream package does not identify a dollar base year in its variable documentation. Do not infer one or compare these numbers directly with a different vintage of GDP data. This extract is suitable for learning commands and discussing association; research requires checking the underlying measurement methodology and the appropriate current source.

The Excel and Stata files made in lesson 2.1 are temporary format conversions of this same CSV, generated under ignored `scratch/`. They introduce no additional observations or data source. The notebook's Colab preparation recreates the same CSV from the same checksum-verified upstream bytes when no local copy exists.

The core path also uses the derived lookup and simulated survey documented below.

## `country_regions.csv`

- **Source and rights:** the same checksum-verified CC0 Gapminder teaching extract above; no independent data source or classification is added. Original source retrieved 2026-11-11.
- **Preparation:** `python scripts/prepare_data.py` writes both the full panel and this 142-row, two-column lookup. It selects distinct `country`/`region` pairs, sorts countries, checks that each country has one region and saves the result. `--check` compares both files without writing.
- **Purpose:** lesson 2.6 removes the region column from a practice copy of the panel and joins it back from this lookup. This teaches key validation and match audits, not the discovery of new regional information. Its fields use the definitions in the country-panel dictionary above.

## `simulated_people.csv`

- **Source:** original, entirely simulated teaching data generated by [scripts/simulate_people.py](../scripts/simulate_people.py). No real respondents, survey programme or restricted microdata are used. There is no external download URL or retrieval date; generated 2026-11-11.
- **Rights:** original course material; licensing remains undecided by owner request. It is not covered by the Gapminder extract's CC0 dedication. No third-party survey redistribution rights are needed because these are fictional records, not copied observations.
- **Reproducibility:** Python's standard-library `random.Random(20261111)` supplies a fixed seed. The script chooses ages, education and employment, constructs an illustrative wage formula and deliberately inserts specified dirty entries. Run `python scripts/simulate_people.py` to regenerate; `--check` verifies the exact committed bytes and shared notebook setup. `--sync-notebooks` updates the tagged simulation setup cell after changing the generator. The notebook embeds the exact generation function so a fresh Colab session can recreate the data without repository authentication.
- **Size:** 120 records, six original columns; one row is one fictional person. There are 19 non-workers, 14 wage non-responses among workers, and nine `unknown` age entries in this exact seed. These counts are properties of the simulation, not population estimates.
- **Limits:** wage relationships are built into the generator. There is no sampling frame, survey weight, real geographic coverage or real dollar base year. Never use these rows to make claims about employment, education or wage returns in an actual population.

| Column | Meaning / coding |
| --- | --- |
| `person_id` | Unique fictional identifier, 1–120; no real person is identified |
| `age` | Age in whole years as numeric text, or literal `unknown`; generated valid ages are 22–64 |
| `education` | Simulation-specific labels secondary, college, university, postgraduate; selected rows deliberately add spaces and uppercase letters |
| `education_years` | Generator's coding convention: 12, 14, 16, 18 respectively; not a cross-country education equivalence |
| `employed` | 1 means employed, 0 means not employed in the simulated response |
| `hourly_wage` | Invented dollars per hour if employed and reported; blank for a non-worker; -99 for worker wage non-response; neither missing code is a real wage |

Lesson 2.4 keeps these raw fields and creates cleaned columns in memory. It does not overwrite the original data. Missing wage reasons are retained rather than recoded to zero. Its deliberately altered four-row country-panel copy is also labelled as practice; it is not a correction to the original Gapminder data.
